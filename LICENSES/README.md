# License Map

The Synthetic Human Brain project separates licensing by artifact type so software, hardware, data, and third-party material are not accidentally treated as the same intellectual-property category.

| Artifact | Default project terms |
|---|---|
| Software/source code | Apache License 2.0 |
| Original hardware designs | CERN-OHL-P-2.0 policy |
| Original project data | CC BY 4.0 |
| Documentation | Apache-2.0 unless a document says otherwise |
| Third-party material | Original provider's license/terms |
| CL1/Cortical Labs proprietary material | Not relicensed; see CL1_NOTICE.md |

These files describe project defaults; a directory-specific license or notice may override the default for that component.
