# Neuron API

Defines the executable neuron contract: membrane state, dendrites, soma, axon, integration, reset, current injection, and spike events.

Implementation starts with existing LIF and other neuron models and expands toward multi-compartment abstractions.

Tests cover thresholding, refractory behavior, reset, deterministic stepping, and spike event provenance.

UML: `../02_neuron_api.puml`.
