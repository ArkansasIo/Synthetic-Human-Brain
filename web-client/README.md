# Researcher Browser Client

TypeScript web client for the Synthetic Human Brain cloud/research server.

The client is intentionally browser-first and uses the same REST + WebSocket protocol as the desktop application.

## Planned UI

- Title / landing page
- Login and session page
- Research workspace dashboard
- Project and experiment tabs
- Brain-region navigation
- Simulation controls
- Live telemetry graphs
- Job monitor
- Source/BrainScript editor
- Dataset and experiment browser
- Server/worker status
- User profile and logout
- Administrator console

The visual language should be an original research workstation interface rather than a copy of another company's website.
